# Brain eval

A document repository whose answers are known, its questions and a deterministic scorer of how a member's agent answers them with the Brain or with plain document reads. Test data only: nothing here is shipped.

How to run it, what it measures and the recorded runs: [docs/development/brain-eval.md](../../../../docs/development/brain-eval.md) ([ADR-0091](../../../../docs/decisions/0091-brain-vectorless-tree-index.md)).

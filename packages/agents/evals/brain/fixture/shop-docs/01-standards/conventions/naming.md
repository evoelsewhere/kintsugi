# Naming

How names are written in the new services.

## Services

Service names are lowercase nouns joined by hyphens, such as `order-pricing`.

## Database tables

Table names are written in snake_case and in the plural, prefixed with the owning service's short code, such as `prc_discounts`.

## Events

Event names are past-tense verbs in PascalCase, such as `OrderPriced`.

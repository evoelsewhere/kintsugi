# Charter

## Objective

Move the order system of Shop off the mainframe batch onto services by the end of the third quarter, without losing an order.

## Scope

In scope: order capture, pricing and invoicing. The warehouse system is out of scope: it keeps its own schedule and is only informed of the dates.

## Milestones

| Milestone | Date |
| --- | --- |
| Pricing live on the new platform | 2027-03-31 |
| Mainframe batch switched off | 2027-09-30 |

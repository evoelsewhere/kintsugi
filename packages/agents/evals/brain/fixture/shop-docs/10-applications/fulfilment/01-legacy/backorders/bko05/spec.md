# Partial deliveries

How a backorder delivered in parts is handled.

## Business rules

### RULE-BKO05-0001: Partial ship

A backorder line is shipped as soon as one unit arrives.

### RULE-BKO05-0002: Partial rest

The rest of the line stays a backorder.

### RULE-BKO05-0003: Partial cost

The customer pays delivery once for the whole line.

# Split shipments

How an order shipped in several parcels is handled.

## Business rules

### RULE-SHP06-0001: Split rule

An order is split when some of its articles are not in stock.

### RULE-SHP06-0002: Split cost

The customer pays delivery once, whatever the number of parcels.

### RULE-SHP06-0003: Split notice

The customer is told of each parcel as it leaves.

# Return labels

How a customer gets a return label.

## Business rules

### RULE-RTN03-0001: Label request

A return label is requested from the order page.

### RULE-RTN03-0002: Label carrier

Return labels are always for Parcelway.

### RULE-RTN03-0003: Label validity

A return label is valid for 14 days.

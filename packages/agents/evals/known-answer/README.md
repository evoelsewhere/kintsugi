# Known-answer eval

A legacy application with planted facts, its answer key and a deterministic scorer of the document repository a run of the built-in plugins wrote to. Test data only: nothing here is shipped or loaded as a plugin.

How to run it, what it measures and the recorded runs: [docs/development/known-answer-eval.md](../../../../docs/development/known-answer-eval.md) ([ADR-0084](../../../../docs/decisions/0084-known-answer-evaluation-of-the-built-in-plugins.md)).

# runtime/

Definitions of Kintsugi's own agents, executed by `services/runtime` on pi.

- `agents/<id>/agent.yaml` — model, tools, policy, budget, triggers, outputs, eval set.
- `skills/<name>/SKILL.md` — Agent Skills used by runtime agents.

Agents: knowledge-ingest, kb-assistant, assessment, wave-planner, to-be-analyst, task-planner, gate-reviewer, insight (docs/reference/runtime-agents.md).

# Authoring and structure

> Research pack, area 10: what a Confluence-like wiki offers for authoring and structure, what Kintsugi has, and the stories to close the gap.

| Page | What it holds |
|---|---|
| [Feature matrix](feature-matrix.md) | 61 features (`AUT-nn`) with public sources, repository status, MoSCoW proposal and persona |
| [User stories](user-stories.md) | Stories `AUT-nn-S<n>` for every Must and Should feature, with Given/When/Then criteria |
| [Gap analysis](gap-analysis.md) | What exists in the code and documents, nine gap clusters, a size per feature |
| [Open questions](open-questions.md) | Questions that meet an accepted ADR, with the architects' decisions |
| [Git-wiki comparison](git-wiki-comparison.md) | How six Git-backed or Markdown-first tools solve order, move, attachments, drafts and export, and what it says about the decisions |

The area covers spaces and the page tree, page operations, the editor, macros and embeds, attachments and images, links and backlinks, drafts and publishing, export and import. Collaboration (comments, mentions, notifications, permissions, version history) and discovery (search, labels, templates) are other areas of the pack.

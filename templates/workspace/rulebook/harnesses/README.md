# Harness renderers

Extra member-harness renderers for this project. Kintsugi already ships renderers for Claude Code, GitHub Copilot, Codex and ChatGPT, and installations can add more (Admin → Harnesses).

- Add a renderer here only when the project uses a harness that is not covered by those.
- List it under `harnesses` in `rulebook.yaml`; the `owners` must approve it.

# Target-base checklist

Convert does not start until every item is checked, by the solution architect.

- [ ] Solution / project structure and layering in place
- [ ] Framework versions pinned
- [ ] Cross-cutting concerns: logging, error handling, configuration, authentication / authorization
- [ ] Data access pattern and migrations set up
- [ ] UI kit / component library and layout templates (if the stack has a UI)
- [ ] Unit / integration test projects and sample tests
- [ ] Build and CI pipeline green on the empty base
- [ ] `conventions/target.md` reflects the base

# `00-project/`

- Written by: people (the program leads)
- Serves: P0 program framing and P1 portfolio; decided at gates G0 and G1 in the portal
- Auto-commit: no — content arrives as pull requests

The project-wide documents agreed before and around the migration work. Read them in this order:

| File | Content | Decided at |
| --- | --- | --- |
| `charter.md` | the objective, scope, success criteria, stakeholders and milestones of the program | G0 |
| `raci.md` | who is responsible, accountable, consulted and informed, and who decides what | G0 |
| `risks.md` | the program risk register: schedule, people, scope and dependencies | G0, reviewed at each gate |
| `ai-strategy.md` | where AI agents apply across the pipeline, where people decide, and the automation target | G0 |
| `ai-usage-policy.md` | what AI may do, with which data and which approvals, and how it is audited | G0 |
| `kpi-baseline.md` | the KPI baseline that later phases report against | G1 |
| `glossary.md` | the project's terms, one row per term with a column per language | continuous |
| `portfolio/` | the portfolio decisions across the applications: scorecard and wave plan | G1 |

Every file starts as a skeleton: the headings and tables are the format the project asks for; replace the guidance in each section with the project's content and delete a section that does not apply. Kintsugi does not generate or validate these files. Gate decisions are recorded in the portal (Governance → Gates), not in this repository.

# Format sample: a unit's card

- Written by: nobody — this is a format sample
- Serves: teach the format of a unit's card, `02-modern/<module>/<unit>/README.md` (P1-P4)
- Auto-commit: no — the name contains `.example`, so nothing loads or seeds these files

`README.md.example` is the card of one unit: its identity and kind, where it comes from (`source`)
and where it goes (`target`), its wave and state, the links to its documents, and the design files a
person waived for it. The `understand` stage proposes the card; the state changes through the
Kintsugi API; a person writes `waived`. Copy it to a real unit folder as `README.md` and adapt it.

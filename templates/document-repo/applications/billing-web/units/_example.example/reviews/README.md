# Unit review records (G4)

Who writes this folder: the `gate-reviewer` runtime job and the human approvers, through a pull request.

Phase and gate: P4 (Build), gate G4. A unit's `unit.md` frontmatter points at its record here.

Auto-commit: **no**. Gate records always arrive as pull-request changes; only `unit.md`, `task.md` and `generated/` are auto-committed.

Format: `G4.md` (see `G4.md.example`) with `decision`, `approvers`, `evidence` (repository paths) and `date`.

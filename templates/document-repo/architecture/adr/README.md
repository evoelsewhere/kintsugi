# `architecture/adr/`

- Written by: people (architects and tech leads)
- Serves: P2-P5; records decisions behind gate G2 and later gates
- Auto-commit: no — records arrive as pull requests

Architecture decision records of this project, one file per decision, numbered in order of
decision. Kinds map to the 7R dispositions (M2C refactor and friends, M2F re-architect and
friends, replatform, M2R repurchase); the decision records the chosen disposition and why.

These records are project content; Kintsugi does not generate or validate them.

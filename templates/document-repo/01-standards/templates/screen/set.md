# Screen design

How a screen of the target system looks and behaves: who may open it and where it leads, each item on it, what happens when the user acts, the validations and messages, and the data it reads and writes. Written from the screen's AS-IS specification and rules before the screen is coded, precise enough that the code can be generated from it. Only for units of kind `screen` (the files come from the profile `screen/`). Replace this set with your project's own format.

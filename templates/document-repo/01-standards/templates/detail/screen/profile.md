# Detail design: screens

A screen is described by what is on it and what happens when the user acts, before the rules behind it. Its logic template adds the layout and the events.

## Instructions

List the items of the screen in reading order, the events in the order a user meets them, and the message of every error exactly as it is shown. A rule that is checked on the screen is cited from the event that triggers it.

# Database object design

How a database object of the target system is defined and reaches a database that already has data: the objects with their columns and constraints, the indexes and access paths, and the migration with its rollback. Written from the object's AS-IS specification and rules before the migration is written. Only for units of kind `db-object` (the files come from the profile `db-object/`).

# <legacy construct> → <target construct>

- **Legacy**: what it is and where it appears (a language feature, a framework facility, a file kind).
- **Target**: what it becomes in the target base (cite `../conventions/target.md`).
- **Recognize it by**: the keyword, naming pattern or file kind that finds every occurrence.
- **Example**:
  ```text
  before: …
  after:  …
  ```
- **Behaviours to preserve**: what the target must do exactly as the legacy construct did.
- **Allowed deviations**: only those covered by an ADR in `../../02-architecture/adr/`.
